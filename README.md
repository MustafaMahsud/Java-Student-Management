# Java Student Management

A beginner Java project built to practice core Java fundamentals through a small student management program.

## 📌 About

This program creates a `Student` object containing:

* Student name
* Student age
* An array of subject marks

It then performs basic calculations on the student's marks.

## ✨ Features

* Takes student information using `Scanner`
* Stores marks in an integer array
* Calculates the average mark
* Finds the highest mark
* Finds the lowest mark
* Counts passed subjects
* Checks whether the student has passed overall
* Uses a `Student` class with a constructor
* Uses methods to separate different operations

## 🛠️ Concepts Practiced

* Java classes and objects
* Constructors
* Arrays
* `Scanner` input
* `for` loops
* `if/else` conditions
* Methods
* Method parameters
* Return values
* Boolean logic
* Basic object-oriented programming

## 🚀 Example

The program asks for information such as:

```text
Enter Student name:
Mustafa

Enter Student age:
19

Enter marks for Subject 1:
78

Enter marks for Subject 2:
65

...
```

It then calculates and displays the student's results.
